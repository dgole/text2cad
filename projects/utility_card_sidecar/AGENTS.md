# Utility Cart Sidecar

Clip-on caddy that hangs on the thin edge of a utility cart. Holds remotes
and pens in top-cut pockets with a solid floor.

## Parts

- **part.py** — single script producing the caddy body + clip hook.

## Build Stages

| Stage       | Purpose                                       |
|-------------|-----------------------------------------------|
| `clip_test` | Thin 20 mm slice + full hook — verify clip fit |
| `body`      | Full solid block + hook — check overall size   |
| `full`      | Complete part with all pockets                 |
